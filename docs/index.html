ScratchJr Reborn

A modernized port of ScratchJr for Web/PWA, Windows, macOS, Linux, and Android — with more room to create, a hardened sandbox, and a fully strict, tested codebase.

🎮 Play in Browser (Web / PWA) Download Desktop / Android

Screenshots

Why Reborn?

  • Universal Multi-Platform — Web/PWA (Chrome, Safari, Edge, Firefox), Desktop (Windows, macOS, Linux), and Native Android with 100% project compatibility
  • In-Browser & PWA Offline — Run directly in any browser on Chromebooks, iPads, and PCs, or install it as an offline standalone app
  • Responsive Mobile Layout — Dynamic scaling for sub-740px smartphone displays with pixel-accurate touch coordinates
  • More room to create — 8 pages by default (configurable), a scrollable page strip, a bigger character sidebar, and + buttons that never disappear
  • Safe & Durable by design — sandboxed desktop renderer, in-browser SQLite with IndexedDB persistence, SQLite WAL on Android, and strict path containment
  • Modern native audio & camera — HTML5 Canvas snapshot feed, WebM Opus audio recording, and native system share sheet integration
  • Trustworthy codebase — all renderer files in strict TypeScript, 157 unit tests passing, automated E2E smoke tests, and CI hygiene guards
  • Reliable releases — multi-platform desktop packages, Android APK/AAB, and instant web app with SHA256 checksums
